# Vellum

A quiet writing desk in the browser. Notebooks, tags, pins, trash, focus mode, and a page that understands a little Markdown.

Notes stay on this device (`localStorage`). Nothing is uploaded.

## Desk

- Notebooks, tags, color labels, pins, search, and trash
- Write, preview, or split Markdown, with an outline of your headings
- Focus mode and typewriter scrolling
- Paper and midnight themes
- Original glass UI tones (synthesized, not copied from any operating system)
- Export a note as Markdown, or the whole library as JSON

## Scripts

```bash
npm install
npm run dev
```

The dev server listens on port `8080`.
